Controller connection

The Inception controller's local Web API is usually reached over HTTPS with a self-signed certificate. If the browser blocks the request, open the base URL directly in a new tab once and accept the certificate warning, then come back here.

Response field mapping

Tell the dashboard where to find each value in the JSON your controller returns. Use the raw response above (Test connection) to check the real field names — these are just common guesses.
If the direction field is empty/not matched for an event, the dashboard falls back to each door's role below (toggle or entry-only).

Doors

Toggle: a reader whose successive swipes alternate a person's status between IN and OUT (your main door). Entry only: a reader that only ever logs entry — exit is a manual, unlogged button (your other 4 doors). Unlisted doors default to entry-only.
