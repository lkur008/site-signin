Controller connection

Uses the Inception REST API: GET /api/v1/control/user/summary for the roster, then GET /api/v1/control/user/{id}/state per user for their current location (Info1). Create/edit an API user in Inception's Manage Users page, set its Web Page Profile to "REST Web API User", and generate a User API Token under Credentials there.

How to read "location"

Inception returns each user's location as free text in Info1 (e.g. an Area name, or something like "Outside"/"Unknown"). Use Test Connection above to see real values from your system, then list which words mean the person is OUT below — anything else is treated as IN. A blank Info1 is always shown as Unknown.
Remember: side doors here only log entry (exit is a manual, unlogged button), so Inception's own location tracking can't see someone leaving that way either — a person may still show as "In" after they've physically left via one of those doors. The main door's toggle reader is the reliable one.
