Settings

Controller connection

Pulls the raw access event log via GET /api/v1/review?categoryFilter=Access through your local proxy (run proxy.py — see the project README/chat for setup). Point this at the proxy's address, not the Inception controller directly.

Doors

Toggle: a reader whose successive swipes alternate a person between IN and OUT (your main door). Entry only: a reader that only ever logs entry — exit is a manual, unlogged button (your other four doors). The door name here must match the "What" field from the event log exactly — use Test Connection above to check the real names. Unlisted doors default to entry-only.

Event classification

Each event's "Description" text is checked against these word lists first; if none match, the door's role above (toggle/entry-only) decides. Comma separated, case-insensitive.

Manual / test data

Paste a JSON array of review events to preview the board without a live connection, e.g. [{"Who":"Jane Smith","What":"Main Door","Description":"Access Granted","When":"2026-08-11T08:02:00Z"}]
